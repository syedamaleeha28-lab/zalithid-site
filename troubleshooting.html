Troubleshooting Zalith Launcher 2

Kumpulan solusi untuk masalah yang paling sering dialami pengguna Zalith Launcher 2 — dari gagal instal, mod tidak muncul, sampai lag saat bermain.

Instalasi & Login

Masalah Saat Instal atau Masuk Akun

ERROR Aplikasi force close saat dibuka pertama kali
Biasanya karena versi Android di bawah 8.0 atau RAM kosong terlalu sedikit. Tutup aplikasi lain di latar belakang, lalu coba buka ulang. Jika masih gagal, unduh ulang APK — file yang korup saat proses download juga bisa menyebabkan ini.
ERROR "Instalasi diblokir" atau "Aplikasi tidak terpasang"
Pastikan sudah mengaktifkan izin instal dari sumber tidak dikenal untuk browser atau file manager yang kamu pakai (Pengaturan → Keamanan → Instal aplikasi tidak dikenal).
ERROR Login akun Microsoft gagal atau macet di layar loading
Periksa koneksi internet, pastikan tanggal & waktu perangkat sudah benar, lalu coba logout-login ulang. Jika masih gagal, gunakan mode akun offline sementara untuk singleplayer.
ERROR Gagal mengunduh versi Minecraft di dalam launcher
Ganti ke jaringan WiFi yang lebih stabil, pastikan ruang penyimpanan cukup, dan coba ulangi unduhan — proses ini sering gagal di koneksi seluler yang tidak stabil.
Performa & Mod

Masalah Saat Bermain

ERROR Mod tidak muncul setelah diinstal
Pastikan versi mod cocok dengan versi Minecraft dan mod loader (Fabric/Forge) yang sedang aktif di launcher. Mod untuk versi Minecraft yang berbeda tidak akan terbaca.
ERROR FPS rendah atau lag saat bermain
Turunkan render distance dan matikan shader dari pengaturan grafis, terutama di perangkat dengan spesifikasi menengah ke bawah. Cek juga halaman pengaturan render lanjutan untuk memilih backend yang paling cocok dengan chipset kamu.
ERROR Game crash saat memakai shader tertentu
Tidak semua shader pack kompatibel dengan semua perangkat. Coba shader lain yang lebih ringan, atau nonaktifkan shader jika crash terus terjadi.
ERROR Skin custom tidak muncul atau kembali ke default
Skin di Minecraft Java Edition tersimpan di akun Microsoft/Xbox Live kamu, bukan di launcher. Pastikan sudah login dengan akun yang sama saat mengganti skin, dan tunggu beberapa saat karena perubahan skin butuh waktu untuk tersinkron ke server Mojang.
ERROR Kontrol sentuh tidak responsif atau posisi berantakan
Buka menu pengaturan kontrol dan atur ulang posisi tombol secara manual — kadang posisi default kurang cocok untuk ukuran layar tertentu.
ERROR Layar hitam setelah masuk ke dunia (world)
Ini sering terkait pengaturan render. Coba ganti backend render di pengaturan lanjutan, dan pastikan perangkat mendukung versi Vulkan/OpenGL yang dibutuhkan.
STORAGE & MEMORI

Masalah Penyimpanan & Memori

Sebagian besar keluhan soal crash atau gagal instal sebenarnya berakar dari ruang penyimpanan yang mepet atau alokasi memori yang kurang pas. Berikut penyebab dan cara mengatasinya.

STORAGE Ruang penyimpanan tidak cukup saat unduh versi Minecraft
Setiap versi Minecraft Java yang diunduh lewat launcher ini memakan ruang cukup besar, apalagi kalau kamu menyimpan beberapa versi sekaligus untuk mod yang berbeda-beda. Kalau muncul pesan penyimpanan tidak cukup, cek dulu sisa ruang kosong di memori internal HP kamu lewat pengaturan sistem. Hapus versi Minecraft lama yang sudah tidak dipakai, kosongkan cache aplikasi lain, atau pindahkan file besar seperti video dan foto ke penyimpanan cloud. Idealnya sisakan ruang kosong minimal beberapa gigabyte agar proses unduh dan ekstraksi file berjalan lancar tanpa terputus di tengah jalan.
MEMORI Aplikasi tertutup sendiri saat memuat dunia besar
Kalau launcher tiba-tiba force close atau kembali ke home screen saat kamu membuka world berukuran besar, kemungkinan besar itu tanda RAM yang dialokasikan kurang mencukupi kebutuhan game. Ini wajar terjadi karena menjalankan Minecraft Java di Android butuh memori lebih banyak dibanding versi Bedrock. Coba turunkan pengaturan grafis seperti render distance dan efek visual sebelum masuk ke dunia yang berat, tutup aplikasi lain yang berjalan di latar belakang, dan kalau ada opsi alokasi RAM di pengaturan launcher, sesuaikan dengan kapasitas RAM HP kamu tanpa mengambil porsi terlalu besar hingga sistem Android sendiri kekurangan memori.
MOD/SHADER File mod atau shader gagal tersalin ke folder yang benar
Mod dan shader pack perlu ditempatkan di folder khusus supaya bisa terbaca oleh game. Kalau file yang kamu pindahkan tidak muncul di daftar mod atau shader, periksa apakah file benar-benar berada di folder yang sesuai instance atau profil Minecraft yang sedang kamu mainkan, bukan tercampur di folder unduhan umum. Pastikan juga format filenya sesuai (biasanya .jar untuk mod dan .zip untuk shader) dan tidak dalam keadaan setengah terunduh atau rusak. Kalau menggunakan aplikasi pengelola file pihak ketiga, pastikan aplikasi tersebut sudah diberi izin akses penyimpanan penuh.
IZIN Muncul pesan izin penyimpanan ditolak
Sejak beberapa versi Android terbaru, sistem operasi jadi lebih ketat soal izin akses file. Kalau muncul pesan izin ditolak, buka pengaturan HP, masuk ke menu Aplikasi, cari launcher ini, lalu pastikan izin penyimpanan atau akses file dan media sudah diaktifkan secara manual. Di beberapa merk HP, kamu juga perlu mengizinkan akses "kelola semua file" khusus untuk aplikasi ini agar mod, shader, dan dunia permainan bisa dibaca dan disimpan dengan normal.

Sudah bebaskan ruang penyimpanan? Pastikan kamu pakai versi terbaru untuk hasil maksimal.

JARINGAN & MULTIPLAYER

Masalah Jaringan & Multiplayer

Main bareng teman lewat server jadi salah satu keseruan utama Minecraft. Kalau koneksi bermasalah, biasanya penyebabnya ada di jaringan itu sendiri, bukan launcher-nya.

KONEKSI Gagal konek ke server multiplayer
Kalau kamu tidak bisa masuk ke server, langkah pertama adalah pastikan alamat IP dan port server sudah kamu ketik dengan benar, termasuk huruf besar-kecil dan titik dua sebelum nomor port kalau memang diperlukan. Cek juga apakah versi Minecraft yang kamu jalankan sama dengan versi yang dipakai server, karena perbedaan versi sering jadi penyebab gagal konek. Selain itu, coba pastikan server memang sedang online dan tidak sedang maintenance, serta cek koneksi internet HP kamu dengan membuka situs atau aplikasi lain terlebih dahulu.
LAG Koneksi terputus-putus saat bermain online
Koneksi yang naik turun biasanya berasal dari sinyal Wi-Fi atau data seluler yang tidak stabil, bukan dari aplikasinya. Kalau memungkinkan, gunakan jaringan Wi-Fi dibanding data seluler karena umumnya lebih stabil untuk sesi bermain yang lama. Hindari juga menjalankan aplikasi lain yang menyedot bandwidth besar secara bersamaan, seperti streaming video atau mengunduh file di perangkat lain yang memakai jaringan sama. Kalau kamu memakai router, coba dekatkan posisi HP atau restart router untuk menyegarkan koneksi.
UNDUHAN Update atau unduhan macet di tengah proses
Proses unduh versi Minecraft, mod, atau resource pack yang macet di persentase tertentu biasanya disebabkan koneksi internet yang terputus sesaat atau server sumber unduhan sedang sibuk. Coba batalkan proses unduh, periksa koneksi internet kamu, lalu ulangi lagi. Kalau sering macet di titik yang sama, coba ganti jaringan (misalnya dari Wi-Fi ke data seluler atau sebaliknya) untuk melihat apakah masalahnya ada di jaringan yang kamu pakai.
PING Ping tinggi atau lag saat main bersama teman
Ping tinggi umumnya dipengaruhi jarak fisik ke server, kualitas jaringan internet, dan jumlah pemain yang sedang online bersamaan. Ini adalah faktor jaringan dan server, bukan sesuatu yang bisa diperbaiki dari sisi launcher. Kalau kamu mengelola server sendiri, pertimbangkan memilih lokasi server yang lebih dekat dengan mayoritas pemain. Sebagai pemain, memakai koneksi Wi-Fi yang stabil dan menghindari penggunaan internet bersamaan untuk kebutuhan berat lain bisa membantu mengurangi lag saat bermain.

Koneksi sudah stabil? Waktunya ajak teman main bareng di server favorit kamu.

PERFORMA

Tips Optimasi Performa Umum

Selain langkah troubleshooting di atas, beberapa kebiasaan sederhana ini bisa membuat pengalaman bermain jadi jauh lebih mulus, terutama di HP dengan spesifikasi menengah ke bawah.

🧹 Tutup Aplikasi Latar Belakang

Aplikasi lain yang masih berjalan di belakang layar ikut memakai RAM dan CPU. Tutup aplikasi yang tidak perlu sebelum bermain supaya sumber daya HP lebih fokus untuk menjalankan game.

🖼️ Turunkan Render Distance

Di HP spesifikasi menengah, mengecilkan render distance dan mengurangi efek grafis bisa meningkatkan frame rate secara signifikan tanpa mengorbankan keseruan bermain.

⚙️ Pilih Backend Render yang Sesuai

Tidak semua chipset bekerja optimal dengan backend render yang sama. Coba bandingkan performa antara Vulkan dan OpenGL di pengaturan untuk menemukan mana yang paling stabil di HP kamu.

📵 Hindari Multitasking Berat

Bermain sambil streaming musik, mengunduh file besar, atau membuka banyak tab browser bisa membebani sistem. Fokuskan sumber daya HP untuk game saat sesi bermain berlangsung.

🔋 Matikan Mode Hemat Daya Ekstrem

Mode hemat baterai yang agresif biasanya membatasi kinerja CPU dan GPU demi menghemat daya, yang berdampak langsung pada penurunan frame rate saat bermain game berat.

🌡️ Jaga Suhu Perangkat

HP yang terlalu panas akan otomatis menurunkan performanya (thermal throttling). Hindari bermain sambil mengisi daya dalam waktu lama, dan beri jeda istirahat kalau perangkat terasa panas.

Terapkan tips di atas lalu rasakan sendiri bedanya saat bermain.

FAQ

Pertanyaan Umum Lainnya

Kenapa Zalith Launcher 2 memakan banyak baterai? +
Menjalankan Minecraft Java lewat lapisan kompatibilitas memang lebih berat dibanding game mobile native, sehingga konsumsi baterai dan panas perangkat wajar lebih tinggi saat bermain lama.
Apakah bisa main multiplayer/server bersama teman? +
Bisa, selama server yang dituju kompatibel dengan versi Minecraft Java yang sama dan kamu terhubung ke internet.
Saya masih terkendala, ke mana harus bertanya? +
Untuk masalah teknis yang lebih spesifik, forum diskusi atau kolom issue di repository GitHub resmi biasanya jadi tempat terbaik karena bisa dijawab langsung oleh komunitas atau pengembang.
Apakah launcher ini butuh koneksi internet terus-menerus? +
Tidak selalu. Koneksi internet dibutuhkan saat pertama kali mengunduh aplikasi, mengunduh versi Minecraft, mod, atau shader, serta saat bermain di server multiplayer online. Setelah semua file terunduh, kamu tetap bisa bermain single player secara offline tanpa koneksi internet aktif.
Kenapa dunia (world) saya hilang setelah update? +
World biasanya tidak hilang, tapi tersimpan di folder instance versi Minecraft tertentu. Kalau setelah update kamu merasa world hilang, coba cek apakah kamu sedang membuka profil atau versi Minecraft yang sama dengan saat world itu dibuat, karena world yang dibuat di satu versi terkadang tidak langsung terlihat di instance versi lain. Sebagai kebiasaan baik, selalu cadangkan folder saves secara berkala sebelum melakukan update besar.
Kenapa performa game saya berbeda dari review atau video orang lain? +
Performa sangat dipengaruhi oleh spesifikasi chipset, RAM, dan kondisi termal masing-masing HP. Dua perangkat dengan nama seri mirip pun bisa punya hasil berbeda tergantung suhu ruangan, usia baterai, dan aplikasi lain yang berjalan. Gunakan hasil orang lain sebagai gambaran umum, lalu sesuaikan pengaturan grafis dengan kondisi perangkat kamu sendiri.

Masalah Teratasi? Saatnya Bermain

Pastikan kamu memakai versi terbaru untuk pengalaman paling stabil.
