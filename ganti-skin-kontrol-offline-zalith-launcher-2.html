Cara Ganti Skin, Atur Kontrol Sentuh & Main Offline di Zalith Launcher 2

Panduan • Diterbitkan 13 September 2026

Tiga pertanyaan yang paling sering muncul soal pengalaman bermain sehari-hari di Zalith Launcher 2: bagaimana ganti skin, bagaimana mengatur ulang kontrol sentuh biar nyaman, dan apakah bisa main tanpa internet. Ini jawaban lengkapnya.

Cara Ganti Skin Minecraft di Zalith Launcher 2

Hal penting yang perlu dipahami dulu: skin Minecraft Java Edition tersimpan di akun Microsoft/Xbox Live kamu, bukan di dalam launcher. Zalith Launcher 2 menjalankan Minecraft Java asli, jadi sistem skin-nya mengikuti sistem resmi Mojang/Microsoft, sama seperti kalau kamu main di PC.

Login dengan Akun Microsoft

Pastikan kamu sudah masuk (login) memakai akun Microsoft yang sama dengan yang dipakai untuk membeli/memiliki Minecraft Java Edition.

Ganti Skin Lewat Situs Resmi Minecraft

Buka halaman profil skin resmi Minecraft (minecraft.net) di browser HP atau perangkat lain, lalu unggah/pilih skin baru menggunakan akun Microsoft yang sama.

Kembali ke Zalith Launcher 2

Buka kembali aplikasi dan masuk ke game. Skin baru akan otomatis tersinkron karena disimpan di akun, bukan di file lokal launcher.

Tunggu Proses Sinkronisasi

Perubahan skin kadang butuh beberapa saat untuk tersinkron penuh ke server Mojang. Kalau skin belum berubah, coba keluar dan masuk ulang ke world/server.

Skin tidak berubah-ubah / kembali ke default? Ini biasanya karena kamu login dengan akun berbeda saat mengganti skin, atau proses sinkronisasi belum selesai. Ini bukan bug khusus Zalith Launcher 2 — perilaku yang sama juga terjadi di Minecraft Java versi PC.

Cara Mengatur Kontrol Sentuh (Touch Controls)

Karena Minecraft Java Edition aslinya dirancang untuk mouse dan keyboard, Zalith Launcher 2 menyediakan lapisan kontrol sentuh virtual (tombol on-screen, joystick pergerakan, tombol aksi) yang bisa dikustomisasi.

🕹️ Atur Ulang Posisi Tombol

Buka menu pengaturan kontrol untuk memindahkan posisi tombol lompat, menyerang, inventaris, dan lainnya sesuai kenyamanan ukuran layar dan gaya pegangan kamu.

🎮 Joystick yang Fleksibel

Sejak versi 2.4.11, komponen joystick virtual dirombak agar bisa disematkan langsung ke dalam layout kustom — bukan lagi elemen kaku yang posisinya terbatas.

👆 Penekanan Lama Berulang

Sejak versi 2.3.3, menekan lama (long press) sebuah tombol bisa memicu event tombol tersebut berulang kali — berguna untuk aksi seperti menghancurkan blok terus-menerus tanpa harus tap berkali-kali.

Kalau kontrol terasa tidak responsif atau posisinya berantakan setelah update, buka menu pengaturan kontrol dan atur ulang posisi tombol secara manual — kadang tata letak default kurang cocok untuk ukuran layar tertentu.

Bisakah Main Zalith Launcher 2 Secara Offline?

Bisa, tapi dengan syarat. Ini pembagian yang perlu kamu pahami:

AktivitasButuh Internet?Keterangan
Mengunduh aplikasi & file Minecraft pertama kaliYaFile versi Minecraft, mod, dan shader perlu diunduh dulu sebelum bisa dipakai offline
Bermain singleplayer setelah file terunduhTidakBisa dimainkan tanpa koneksi internet aktif
Bermain di server multiplayer onlineYaTermasuk fitur Terracotta untuk main bareng teman
Login pertama kali dengan akun MicrosoftYaDiperlukan untuk verifikasi kepemilikan game
Soal "akun offline": mode akun offline biasanya dipakai sebagai jalan sementara untuk tetap bisa bermain singleplayer ketika login akun Microsoft sedang gagal atau macet di layar loading — bukan cara resmi untuk melewati kepemilikan game. Kalau login Microsoft kamu bermasalah, periksa koneksi internet dan tanggal/waktu perangkat, lalu coba logout-login ulang.

Masalah Login yang Sering Terjadi

Login akun Microsoft gagal atau macet di layar loading adalah salah satu keluhan paling umum. Langkah dasarnya: periksa koneksi internet, pastikan tanggal & waktu perangkat sudah benar, lalu coba logout-login ulang. Untuk daftar solusi lengkap masalah instalasi dan login lainnya, cek halaman troubleshooting.

FAQ

Apakah skin custom bisa disimpan langsung di Zalith Launcher 2 tanpa akun Microsoft?
Tidak. Sistem skin Minecraft Java Edition terikat ke akun Microsoft/Xbox Live secara resmi, bukan ke aplikasi launcher tertentu.
Kenapa kontrol sentuh saya tiba-tiba berantakan setelah update aplikasi?
Pembaruan aplikasi kadang mengubah struktur sistem kontrol (seperti pada joystick di versi 2.4.11). Buka menu pengaturan kontrol dan atur ulang posisi tombol secara manual.
Apakah saya bisa main Minecraft di Zalith Launcher 2 tanpa internet sama sekali, dari awal instal?
Tidak. Koneksi internet tetap dibutuhkan minimal sekali di awal untuk mengunduh aplikasi, file versi Minecraft, dan untuk proses login akun.

Fakta seputar sistem skin, kontrol, dan mode offline disusun berdasarkan perilaku resmi Minecraft Java Edition serta catatan rilis resmi ZalithLauncher2 di GitHub.
