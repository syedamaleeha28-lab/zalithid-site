Zalith Launcher 2 di iOS, PC, atau Play Store?

Jawaban singkatnya: Zalith Launcher 2 saat ini hanya tersedia untuk Android, didistribusikan lewat GitHub — bukan Play Store. Berikut rinciannya per platform.

Per Platform

Status Ketersediaan

📱 Google Play Store

Zalith Launcher 2 tidak tersedia di Google Play Store. Alasan teknis dan kebijakan di baliknya sudah dibahas panjang lebar di halaman Sumber Resmi & GitHub — singkatnya, distribusinya lewat rilis resmi di GitHub, bukan toko aplikasi. Waspadai aplikasi dengan nama mirip yang beredar di toko aplikasi pihak ketiga — itu bukan rilis resmi proyek ini.

🍎 iOS / iPhone / iPad

Zalith Launcher 2 tidak tersedia untuk iOS dan tidak ada rencana resmi yang dipublikasikan untuk versi iOS. Kebijakan sideloading Apple yang jauh lebih ketat dibanding Android membuat jenis aplikasi seperti ini — yang menjalankan JVM dan file game pihak ketiga — jauh lebih sulit didistribusikan di ekosistem iOS. Kalau kamu menemukan file ".ipa" yang mengaku sebagai Zalith Launcher untuk iOS di luar repository resmi, perlakukan dengan sangat hati-hati; verifikasi dulu lewat halaman Sumber Resmi sebelum mengunduh apa pun.

💻 PC / Windows / macOS

Zalith Launcher 2 dibuat khusus untuk menjembatani Minecraft Java Edition ke Android — kebutuhan seperti ini tidak ada di PC, karena Minecraft Java Edition sudah berjalan native di Windows, macOS, dan Linux lewat launcher resmi Minecraft dari Mojang. Kalau kamu bermain di PC, cukup pakai launcher resmi Minecraft, bukan Zalith Launcher 2.

🤖 Android

Ini satu-satunya platform resmi yang didukung. Lihat cara download dan panduan instalasi di halaman utama.

FAQ

Pertanyaan Umum

Apakah ada rencana rilis iOS di masa depan? +
Tidak ada pengumuman resmi soal ini dari proyek ZalithLauncher2. Kalau ada perkembangan, informasi resminya akan selalu ada di repository GitHub proyek, bukan di sumber lain.
Kenapa saya menemukan "Zalith Launcher APK" di toko aplikasi pihak ketiga? +
Beberapa situs pihak ketiga menghost ulang atau memakai nama serupa untuk aplikasi yang belum tentu sama dengan rilis resmi. Selalu bandingkan dengan sumber resmi di GitHub sebelum mengunduh dari tempat lain — lihat panduannya di sini.
Saya main di PC, apa saya tetap butuh Zalith Launcher 2? +
Tidak. Zalith Launcher 2 hanya relevan kalau kamu ingin main Minecraft Java Edition di Android. Di PC, pakai launcher resmi Minecraft langsung.
