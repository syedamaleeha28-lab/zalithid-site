Login Akun Microsoft Gagal di Zalith Launcher 2?

Login gagal atau macet di layar loading adalah salah satu kendala paling sering dialami saat pertama kali membuka Zalith Launcher 2. Kabar baiknya, hampir semua kasus bisa diatasi sendiri lewat langkah-langkah di bawah ini.

Login Microsoft Langkah Bertahap
Langsung ke Solusi Kenapa Ini Terjadi
Pengantar

Kenapa Minecraft Java Butuh Login Microsoft?

Minecraft Java Edition mewajibkan login dengan akun Microsoft (yang sudah menghubungkan lisensi Minecraft/Xbox) untuk memverifikasi kepemilikan game asli dan menyinkronkan data seperti skin serta akses server tertentu. Zalith Launcher 2, sebagai launcher yang menjalankan Minecraft Java asli di Android, mengikuti alur login yang sama seperti launcher resmi di PC — bukan sistem login buatan sendiri.

Karena prosesnya melibatkan server Microsoft di luar kendali launcher, sebagian penyebab gagal login memang di luar aplikasi itu sendiri, tapi sebagian besar tetap bisa diperbaiki dari sisi HP kamu.

Diagnosis

Penyebab Umum Login Gagal

  • Koneksi internet tidak stabil — proses autentikasi Microsoft butuh koneksi yang konsisten selama beberapa detik penuh, bukan cuma tersambung sesaat.
  • Tanggal & waktu perangkat salah — sistem autentikasi berbasis token sangat sensitif terhadap jam sistem yang tidak sinkron. Kalau tanggal/waktu HP kamu meleset, proses verifikasi token bisa ditolak.
  • Cache aplikasi yang korup — sisa data login lama yang rusak kadang membuat proses baru ikut gagal.
  • Gangguan sementara di server Microsoft/Xbox — di luar kendali launcher maupun HP kamu, biasanya pulih sendiri dalam beberapa saat.
  • Verifikasi keamanan akun (2FA) belum diselesaikan — kalau akun Microsoft kamu memakai autentikasi dua langkah, proses tambahan itu perlu diselesaikan sampai tuntas di jendela login, bukan ditutup di tengah jalan.
Langkah Demi Langkah

Cara Mengatasinya

  1. Cek koneksi internet. Pastikan WiFi atau data seluler kamu benar-benar stabil — coba buka situs lain dulu untuk memastikan.
  2. Perbaiki tanggal & waktu HP. Masuk ke Pengaturan → Tanggal & Waktu, aktifkan opsi "Atur otomatis" supaya jam perangkat selalu sinkron dengan jaringan.
  3. Logout lalu login ulang. Kalau ada opsi logout di menu akun launcher, keluar dulu sebelum mencoba login dari awal.
  4. Bersihkan cache aplikasi. Lewat Pengaturan HP → Aplikasi → Zalith Launcher 2 → Penyimpanan → Hapus Cache (bukan Hapus Data, supaya file game yang sudah diunduh tidak ikut hilang).
  5. Selesaikan verifikasi keamanan sampai tuntas. Kalau muncul permintaan kode 2FA atau konfirmasi perangkat baru dari Microsoft, selesaikan prosesnya sebelum menutup jendela login.
  6. Cek status akun lewat browser. Buka account.microsoft.com di browser HP untuk memastikan akun kamu sendiri tidak sedang terkunci atau butuh verifikasi tambahan di luar aplikasi.
  7. Update ke versi terbaru. Kalau semua langkah di atas belum berhasil, pastikan kamu memakai versi Zalith Launcher 2 terbaru — bug login kadang sudah diperbaiki di rilis setelahnya.
Sementara

Mode Offline Sebagai Jalan Pintas Sementara

Kalau kamu cuma butuh main singleplayer dan login masih bermasalah, sebagian besar launcher Java-Android termasuk Zalith Launcher 2 menyediakan mode akun offline sebagai solusi sementara. Perlu diingat, mode ini punya batasan — tidak bisa dipakai untuk multiplayer online, skin custom, atau fitur yang butuh verifikasi akun asli. Penjelasan lengkap batas-batasnya ada di panduan skin, kontrol & mode offline.

FAQ

Pertanyaan Umum

Apakah login gagal berarti akun saya bermasalah? +
Tidak selalu. Penyebab paling umum justru dari sisi HP (koneksi, jam sistem, cache), bukan akun Microsoft itu sendiri. Cek dulu langkah-langkah di atas sebelum menganggap akunnya bermasalah.
Berapa lama biasanya gangguan server Microsoft pulih? +
Bervariasi, tapi umumnya hanya hitungan menit hingga beberapa jam. Kalau semua langkah di HP sudah dicoba dan tetap gagal, kemungkinan besar memang sedang ada gangguan di sisi server dan tinggal menunggu.
Saya sudah coba semua tapi tetap gagal, harus bagaimana? +
Lanjut ke halaman troubleshooting lengkap untuk kendala lain, atau tanyakan detail masalahmu di forum/kolom Issues GitHub resmi supaya bisa dibantu komunitas.

Login Sudah Berhasil?

Pastikan kamu memakai versi terbaru untuk pengalaman paling stabil.
