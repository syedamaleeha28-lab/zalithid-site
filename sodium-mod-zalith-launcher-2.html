Cara Install Sodium Mod di Zalith Launcher 2

Pasang Sodium lewat Mod Browser bawaan (Fabric) — tanpa pindah file .jar manual — supaya FPS Minecraft Java di Android lebih lancar.

Pengantar

Sodium di Android, Lewat Zalith Launcher 2

Sodium adalah mod yang mengganti mesin render Minecraft supaya FPS naik dan micro-stutter berkurang. Di HP, mod ini jalan di Minecraft Java Edition — termasuk lewat Zalith Launcher 2, karena aplikasinya sudah punya dukungan Fabric.

Kamu tidak perlu merakit folder mods sendiri: Zalith Launcher 2 punya layar Download Mod. Kalau kamu baru pasang launcher dan masih bingung soal Java di Android, baca dulu apakah perlu install Java terpisah — runtime-nya sudah ada di dalam aplikasi.

Dasar

Apa Itu Sodium?

Sodium adalah pengganti mesin render berperforma tinggi untuk Minecraft. Tujuannya sederhana: frame rate yang lebih baik dan micro-stutter yang lebih sedikit.

Sodium membutuhkan mod loader Fabric (juga bisa dengan NeoForge/Quilt, tapi panduan ini fokus ke Fabric karena itu setup yang paling umum di Zalith Launcher 2).

Persiapan

Syarat Sebelum Install

  • Zalith Launcher 2 sudah terinstall dan bisa buka Minecraft versi vanilla dengan normal.
  • Fabric harus sudah diinstall untuk versi Minecraft yang kamu mau pakai (dari layar Download → Game, pilih versi Minecraft kamu, lalu pilih Fabric sebagai mod loader — Fabric sudah tersedia di Zalith Launcher 2).
  • Koneksi internet stabil untuk proses download mod.
Cara pakai

Cara Install Sodium di Zalith Launcher 2

Alur di bawah mengikuti Mod Browser bawaan aplikasi — bukan salin .jar ke folder mods.

  1. Buka Zalith Launcher 2, lalu tap ikon Mod di sidebar kiri (ikon puzzle piece, di antara “Modpack” dan “Resource Pack”). Ini akan membuka layar Download - Mod.
  2. Di kolom pencarian, ketik Sodium lalu tap hasil Sodium yang muncul (ikon hijau dengan logo api/tetesan, deskripsi “A high-performance rendering engine replacement for Minecraft, which greatly improves frame rates and reduces micro-stutter”).
  3. Setelah masuk ke halaman detail Sodium, kamu akan melihat daftar versi Sodium yang tersedia, masing-masing diberi label versi Minecraft dan mod loader-nya (contoh: “26.2 Fabric”, “26.1.2 Fabric”, ada juga varian NeoForge). Gunakan kolom Search MC Versions untuk mencari versi Minecraft yang sama persis dengan yang kamu pakai.
  4. Pilih baris yang cocok dengan versi Minecraft kamu DAN bertuliskan Fabric (bukan NeoForge, kecuali kamu memang pakai NeoForge). Tap tombol Download di pojok kanan atas untuk mengunduh dan memasang mod tersebut.
  5. Setelah proses download selesai, buka game dengan profil/versi Fabric yang sudah kamu siapkan tadi. Sodium akan otomatis aktif — tidak perlu memindahkan file .jar secara manual ke folder mods, semuanya sudah ditangani oleh Mod Browser bawaan ini.
Tips: pastikan versi Sodium yang kamu pilih sama persis dengan versi Minecraft yang kamu mainkan. Kalau versinya beda, mod tidak akan jalan atau game bisa crash saat dibuka.
Manfaat

Kenapa Harus Pakai Sodium?

  • FPS lebih tinggi dibanding render vanilla.
  • Mengurangi stutter atau lag saat dunia dimuat dan kamera bergerak.
  • Tidak mengubah gameplay atau visual dasar game.
  • Aman dipakai di server multiplayer yang mengizinkan mod client-side seperti Sodium.
Kalau macet

Sodium Tidak Muncul atau Error? Coba Ini

  • Pastikan Fabric sudah terinstall dulu untuk versi Minecraft yang sama.
  • Pastikan versi Sodium yang didownload cocok dengan versi Minecraft (bukan versi lain).
  • Coba restart aplikasi setelah download selesai.
  • Pastikan penyimpanan HP masih cukup.

Kalau launcher-nya sendiri yang force close, login gagal, atau folder game tidak kebaca, lanjut ke panduan troubleshooting lengkap.

Sodium urusan render. Kalau kamu juga mau shader (tampilan air, bayangan, dan langit yang lebih “PC”), Iris Shaders akan segera dibahas di artikel terpisah. Sementara itu, mulai dari panduan lengkap Zalith Launcher 2 kalau belum pasang launcher-nya.
