Cara Main Multiplayer Bareng Teman

Cara Join Server Multiplayer

Karena Zalith Launcher 2 menjalankan file game Minecraft Java Edition yang sama seperti di PC, cara join server-nya pun identik dengan menu multiplayer Java di PC.

  1. Buka game lewat profil yang sudah kamu siapkan, lalu masuk ke menu Multiplayer dari layar utama Minecraft.
  2. Tap Add Server (Tambah Server).
  3. Isi Server Name (bebas) dan Server Address — biasanya berupa alamat IP atau domain, kadang disertai nomor port setelah tanda titik dua (contoh: play.contohserver.com:25565).
  4. Simpan, lalu tap dua kali nama server di daftar untuk join.
Penting: versi Minecraft yang kamu jalankan harus cocok dengan versi yang dipakai server tersebut. Server yang berjalan di Minecraft 1.20.1 misalnya, umumnya tidak bisa dimasuki dari game versi 1.21.x tanpa plugin khusus di sisi server. Kalau gagal konek, cek dulu bagian jaringan & multiplayer di halaman troubleshooting.

Open to LAN: Main Bareng Tanpa Setup Server

Kalau kamu cuma mau main cepat bareng teman yang ada di jaringan WiFi yang sama, tidak perlu bikin/menyewa server sendiri. Minecraft Java Edition punya fitur bawaan Open to LAN yang membuka world single player kamu supaya bisa dimasuki perangkat lain di jaringan yang sama untuk sementara.

  1. Buka world single player yang mau kamu mainkan bareng.
  2. Tekan tombol menu/pause (Esc di keyboard, atau tombol menu di kontrol sentuh).
  3. Pilih Open to LAN.
  4. Atur Game Mode dan opsi cheat kalau perlu, lalu tap Start LAN World.
  5. Game akan menampilkan nomor port yang aktif — teman yang berada di jaringan WiFi yang sama bisa melihat world ini otomatis muncul di daftar server mereka, atau join manual pakai IP HP kamu + port tersebut.
Batasan: Open to LAN hanya berfungsi kalau semua pemain terhubung ke jaringan WiFi/lokal yang sama — tidak bisa dipakai untuk main bareng teman yang beda lokasi lewat internet. Untuk itu, kamu butuh server yang bisa diakses publik lewat alamat IP tetap.

Kenapa Teman Saya di HP Lain Tidak Bisa Join?

Penyebab paling umum: teman kamu main Minecraft Bedrock Edition (versi resmi Play Store/App Store), sementara Zalith Launcher 2 menjalankan Minecraft Java Edition. Kedua edisi ini punya sistem multiplayer yang terpisah dan tidak bisa saling terhubung secara langsung — pemain Java hanya bisa main bareng sesama pemain Java, dan pemain Bedrock hanya bisa dengan sesama Bedrock. Penjelasan lengkap perbedaan keduanya ada di Minecraft Java vs Bedrock di Android.

Kalau teman kamu ingin main bareng lewat Zalith Launcher 2, mereka juga perlu memakai launcher yang menjalankan Minecraft Java Edition (Zalith Launcher 2 atau launcher Java-Android sejenis), bukan aplikasi Minecraft resmi dari Play Store.

Opsional

Realms

Karena Zalith Launcher 2 menjalankan Minecraft Java Edition asli dan login memakai akun Microsoft yang sama, langganan Minecraft Realms yang sudah kamu miliki seharusnya bisa diakses dengan cara yang sama seperti di PC — cukup login dengan akun Microsoft yang terdaftar sebagai pemilik/anggota Realm, lalu cari opsi Realms di menu multiplayer. Kalau kamu mengalami kendala akses Realms secara spesifik, itu di luar cakupan panduan ini karena bergantung pada layanan Realms milik Mojang, bukan launcher-nya.

FAQ

Pertanyaan Umum

Apakah butuh koneksi internet untuk Open to LAN? +
Tidak wajib internet aktif, yang penting semua perangkat terhubung ke jaringan WiFi/lokal yang sama (hotspot HP juga bisa dipakai sebagai jaringan lokal).
Bisa main bareng pemain PC? +
Bisa, selama sama-sama Minecraft Java Edition dan bergabung ke server/world yang sama. Java Edition di Android lewat Zalith Launcher 2 pada dasarnya kompatibel dengan Java Edition di PC.
Server sudah benar tapi tetap gagal konek, harus bagaimana? +
Cek IP/port, versi Minecraft, dan status server di panduan troubleshooting jaringan & multiplayer — sebagian besar kasus gagal konek disebabkan salah satu dari ketiga hal tersebut.

Siap Main Bareng Teman?

Pastikan versi Minecraft dan mod loader kamu sama dengan server/teman yang mau kamu ajak main.
