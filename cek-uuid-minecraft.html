Cara kerja

3 Langkah Sederhana

Tidak perlu install apa pun untuk mulai — cukup buka halaman ini di browser.

Masukkan username

Ketik username Minecraft Java Edition yang ingin dicek pada kolom di atas.

Klik "Cek UUID"

Alat akan mencari data akun tersebut dan menampilkan hasilnya dalam hitungan detik.

Salin UUID yang dibutuhkan

Gunakan tombol Salin untuk menyalin UUID dengan atau tanpa strip, sesuai kebutuhan (plugin, whitelist server, dll).

Untuk siapa alat ini

Berguna untuk Admin Server hingga Developer

UUID sering dibutuhkan di luar sekadar bermain: admin server memakainya untuk whitelist yang tidak berubah walau pemain ganti nama, developer plugin memakainya sebagai kunci data pemain, dan pemain biasa memakainya untuk memastikan akun mana yang sedang mereka cek.

Alat ini mengambil data langsung dari layanan publik yang menyimpan riwayat akun Minecraft, jadi hasilnya sesuai dengan akun resmi — bukan sekadar menghasilkan kode acak dari teks yang diketik.

Cocok dipakai untuk

Whitelist server yang tidak putus saat pemain ganti username.

Konfigurasi plugin/mod yang butuh identitas akun tetap.

Memastikan avatar/skin yang muncul benar milik akun yang dicari.

FAQ

Pertanyaan Seputar Alat Cek UUID

Apakah alat ini gratis? +
Ya, sepenuhnya gratis dan tidak perlu login atau mendaftar akun apa pun.
Apakah username saya disimpan? +
Tidak. Pencarian dikirim langsung dari browser kamu ke layanan pencari akun, dan halaman ini tidak menyimpan riwayat pencarian di server mana pun.
Kenapa username saya tidak ditemukan? +
Biasanya karena salah ketik, akun belum pernah login online-mode, atau akun tersebut memang belum/tidak terdaftar. Coba periksa ejaannya lagi.
Apakah ini berlaku untuk akun Bedrock Edition? +
Tidak. Java Edition dan Bedrock Edition memakai sistem UUID yang terpisah karena keduanya produk berbeda. Alat ini khusus untuk akun Java Edition.
Bisakah alat ini dipasang sebagai aplikasi? +
Bisa. Di Chrome/Edge desktop maupun Android, akan muncul tombol "Install App" di pojok kanan atas setelah halaman selesai dimuat — klik untuk memasangnya seperti aplikasi biasa.
Bagaimana cara melihat skin karakter Minecraft saya? +
Buka tab "Lihat Skin" di atas, masukkan username, lalu klik "Lihat Skin". Kamu akan melihat render karakter lengkap dan bisa mengunduh tekstur skin-nya dalam format PNG.
Apa itu fitur Cek Status Server? +
Fitur ini menunjukkan apakah sebuah server Minecraft Java sedang online, berapa jumlah pemain yang aktif, versi server, dan MOTD (pesan sambutan) — berguna sebelum bergabung ke server tertentu.
