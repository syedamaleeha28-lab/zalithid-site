Ringkasan

Jawaban Singkat: Kode Akun, Bukan Nama

UUID (Universally Unique Identifier) adalah kode tetap yang diberikan Mojang/Microsoft ke setiap akun Minecraft — terpisah dari username. Nama yang kamu lihat di game bisa berubah; UUID di belakang layar tidak.

UUID-lah yang benar-benar menghubungkan skin, cape, item yang dibeli, serta data world/server ke akun. Bukan username. Itu sebabnya mengganti nama Minecraft tidak membuat kamu kehilangan item, world, atau progres.

Intinya: username = label yang bisa diganti. UUID Minecraft = identitas akun yang tetap.

Yang menempel ke UUID

Skin dan cape mengikuti akun (UUID), bukan tulisan nama di atas kepala.

Item yang dibeli dan data world/server tertaut ke UUID yang sama.

Ganti display name? UUID tidak berubah, jadi progres tetap di akun itu.

Akun & edisi

UUID Online-mode vs Nama yang Diketik Saja

Akun Java Edition yang sah, dibeli, dan masuk dengan akun Microsoft mendapat UUID online-mode yang tertaut ke akun nyata itu.

✅ Login Microsoft

Akun Java Edition resmi yang masuk dengan akun Microsoft memakai UUID online-mode yang terikat ke akun itu — identitas yang server dan layanan Mojang kenali.

📝 Tanpa login Microsoft

Akun yang tidak masuk dengan akun Microsoft nyata (mode offline / tanpa login) mendapat jenis UUID lain yang dihasilkan hanya dari username yang diketik.

☕ Java vs Bedrock

Java Edition dan Bedrock Edition memakai sistem UUID yang terpisah dan berbeda, karena keduanya produk yang berbeda. Ringkasannya ada di Minecraft Java vs Bedrock di Android.

Halaman ini satu cluster dengan FAQ teknis lain di situs, misalnya apakah perlu install Java terpisah di Android. Untuk main Java Edition di HP, mulai dari Zalith Launcher 2.

Catatan teknis

Kenapa Akun yang Benar-benar Login Lebih Andal

Ini catatan fakta, bukan panduan menyalakan mode apa pun: UUID yang hanya dihasilkan dari username yang diketik membuat akun semacam itu sering tidak bisa masuk server yang mewajibkan verifikasi online-mode. Dua orang berbeda yang main offline dengan username sama juga secara teknis bisa berakhir dengan identitas yang bentrok.

Online-mode — akun nyata yang sudah masuk — lebih andal karena UUID-nya tertaut ke akun Microsoft/Mojang, bukan ke teks nama yang bisa diketik siapa saja. Kalau login Microsoft macet atau akun tidak terbaca di game, cek troubleshooting Zalith Launcher 2, bukan ganti-ganti username berulang kali.

Untuk pemula: anggap UUID sebagai “nomor induk” akun. Nama di layar boleh berganti; nomor itu yang membuat skin, cape, dan progres tetap milikmu.

Main Java Edition di Android dengan akun yang sudah masuk — UUID-nya yang menjaga data akun.

Pertanyaan Seputar UUID Minecraft

Apa itu UUID Minecraft? +
UUID (Universally Unique Identifier) adalah kode tetap yang diberikan Mojang/Microsoft ke setiap akun Minecraft. Kodenya terpisah dari username.
Kalau saya ganti username, apakah item dan world hilang? +
Tidak karena itu. Skin, cape, item yang dibeli, dan data world/server tertaut ke UUID, bukan ke nama tampilan. UUID tidak berubah meski display name diganti.
UUID Java dan Bedrock sama? +
Tidak. Java Edition dan Bedrock Edition memakai sistem UUID yang terpisah karena keduanya produk berbeda.
Apa bedanya UUID online-mode? +
Akun Java Edition yang sah, dibeli, dan masuk dengan akun Microsoft mendapat UUID online-mode yang tertaut ke akun nyata itu. Tanpa login Microsoft, UUID-nya jenis lain — dihasilkan dari username yang diketik — jadi sering ditolak server online-mode dan bisa bentrok antar pemain offline dengan nama sama.
Login Microsoft gagal. Apakah UUID saya rusak? +
Bukan kesimpulan yang tepat. Kalau masuk akun macet, mulai dari troubleshooting launcher — itu lebih relevan daripada mengutak-atik identitas akun.
